ROC Curve Comparison

All three models cluster within 0.008 ROC-AUC of each other on this dataset, so the ceiling here is set mostly by the 19 available features, not by which algorithm reads them. Accuracy is lower than a typical churn tutorial (~80%) on purpose — all three models trade some accuracy for recall (catching ~79–80% of actual churners instead of ~51%), since missing a real churner usually costs more than one unnecessary retention offer. Probabilities are re-calibrated to undo the inflation that class weighting causes, so “30%” means roughly 30 in 100 similar customers churn.

Where to draw the line

A model outputs a probability; you choose how likely a customer must be before it flags them. Lower catches more churners but raises false alarms — which is why accuracy alone can mislead. This threshold is also used by the Predict page.

What this is

A churn-risk tool that doesn't just say "at risk" — it compares three different models on the same customer and shows, feature by feature, why each one reached its answer. Built around the idea that a prediction stakeholders can't inspect isn't one they'll act on.

How it works

  1. Answer the step-by-step questions about a customer (demographics, services, billing).
  2. The API encodes those answers exactly the way the training data was encoded, then scores them.
  3. SHAP explains the individual prediction; all three models run side by side for comparison.

Dataset

IBM Telco Customer Churn — 7,043 customers, 19 features across demographics, subscribed services, and account/billing details, with a 26.5% churn rate. Shipped in this project as data/telco_churn.csv.

Under the hood

Models compared

Logistic Regression, Random Forest, and XGBoost — each hyperparameter-tuned via cross-validated grid search. See the Model Performance tab for live metrics.

Stack

  • Frontend — vanilla JS (ES6 modules), Tailwind utilities, Chart.js
  • Backend — FastAPI, scikit-learn, XGBoost, SHAP
  • Data — SQLite prediction log, pandas pipeline
  • Ops — Docker Compose, MLflow experiment tracking

Predictions are model estimates based on historical patterns, not guarantees about any individual customer.
